# Job Application Tracker

A Django web application for tracking and managing job applications.

## About the Project

Job Application Tracker is a web application built using Django that helps users organize and manage their job applications in one place.

Users can add new job applications, update existing applications, delete applications, search by company or role, and filter applications based on their current status.

## Features

- Add new job applications
- View all job applications
- Edit existing applications
- Delete applications with confirmation
- Search applications by company or role
- Filter applications by status
- Sort applications by newest date
- View application status statistics
- Calculate interview rate
- Display interview progress visually

## How to Run the Project

1. Clone the repository
2. Create and activate a virtual environment
3. Install Django
4. Run database migrations
5. Start the development server
6. Open the application in the browser
